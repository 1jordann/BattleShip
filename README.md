Battleship Game (C)
A console-based Battleship game written in C. Players enter coordinates on a 10×10 grid to find and hit ships randomly placed by the computer. 

Feature: Random placement of five hidden ships, 10×10 game board, Hit and miss detection, Coordinate input validation, Tracking of previous guesses, 
Win condition when all ship positions are hit

Technologies Used: C, Multidimensional arrays, Loops and conditional statements, Functions, Standard input/output

How to Run:
Compile the program using GCC or Clang:
cc main.c -o battleship

Run the game:
./battleship

How to Play
Start the program.
Enter a coordinate such as A1 or B5.
The program displays whether the shot was a hit or miss.
Continue guessing until all ship positions are hit.
The game uses X to represent hits, O for misses, and . for unexplored positions.

About the Project: This project demonstrates foundational C programming concepts, 
including array manipulation, coordinate handling, conditional logic, functions, input validation, and game-state tracking.
